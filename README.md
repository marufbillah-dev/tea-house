# Tea House Project

Welcome to the Tea House Project! This is a simple web project designed to showcase a tea house website. The project uses modern design principles and is styled with Tailwind CSS.

## Features
- **Tailwind CSS**: The project is styled using Tailwind CSS, a utility-first CSS framework.
- **Static Website**: This is a static website with an `index.html` file and accompanying CSS and image assets.
- **Tea House Theme**: The design and content are tailored to represent a tea house.

## Limitations
- **Not Responsive**: The current design is not responsive and may not display correctly on all screen sizes.

## Project Structure
```
index.html       # Main HTML file
style.css        # Additional CSS styles (if any)
images/          # Folder containing image assets
```

## Technologies Used
- **HTML5**: For the structure of the website.
- **CSS3**: For additional styling.
- **Tailwind CSS**: For utility-first CSS design.

## Future Improvements
- Make the design responsive for better usability on mobile devices.
- Add more interactivity using JavaScript.
